Privacy Policy for DevTools Full-Spectrum Assistant

Updated September 30, 2026.

Inspection and cloud analysis

Opening the Fix Assistant panel starts an audit of the inspected page. The extension reads page structure, metadata, URLs, form attributes, accessibility findings, observed runtime errors and failed requests. A compact DOM excerpt and diagnostic evidence are sent to the hosted service at cite.archpanda.xyz, which calls Anthropic Claude. Input value attributes and textarea contents are removed from the DOM excerpt, and entered form values are excluded from the form metadata. Other website content, URLs and application-generated errors may still contain personal or sensitive information. Use the extension on pages you are authorized to inspect.

Clicking Explain sends the selected error and page context to the configured diagnose endpoint. Repeated explanations within an audit are cached. Custom endpoints receive the same request data and any configured API key; their operators control their own retention and privacy practices. Direct model endpoints require a compatible adapter.

Repairs and reports

Cloud responses provide diagnostic text, supported repair operation identifiers and suggested source patches. Apply buttons run only fixed repair functions bundled with the extension. Cloud-provided scripts, arbitrary selectors and executable expressions are not executed. Source patches are text for manual review and export. DOM changes are temporary. Reports and saved baselines may include locally inspected page content, origins, error messages and issue signatures.

Accounts and local storage

An anonymous random installation identity is stored locally and sent to the backend to track the free monthly allowance across tabs and browser restarts. Server records contain the identity, allowance, tier, quota period and usage events. License keys, custom API keys, endpoint settings and last verified quota are stored locally until removed, reset or replaced. License keys are sent for verification. The device does not retain a history of unrelated browser tabs.

Payments and providers

Stripe handles checkout. Paid license records can contain customer email, checkout session identifiers, tier and usage balance. Anthropic and configured endpoint operators process diagnostic requests under their respective data practices. Removing the extension removes its local storage but does not delete server or payment-provider records.

Contact

The extension contains no analytics feature or browsing-history collection. Data is not sold or used for advertising, lending or creditworthiness decisions. For support or a request concerning server-held records, contact support@archpanda.xyz.
